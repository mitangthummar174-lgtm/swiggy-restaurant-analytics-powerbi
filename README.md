# Swiggy Restaurant Analytics Dashboard | Power BI

An interactive Power BI dashboard developed to analyze Swiggy restaurant data and generate meaningful insights through data visualization.

## 📊 Dashboard Overview

The dashboard provides an overview of restaurant data through key metrics and interactive visualizations.

### Key KPIs

- Total Restaurants
- Cities Covered
- Average Restaurant Rating
- Average Cost for Two
- Primary Cuisine

### 📈 Key Analysis

- Top 10 cities by restaurant count
- Top 5 cuisines by restaurant count
- Restaurant rating distribution
- City-wise restaurant analysis
- Restaurant-level details
- Cuisine and rating analysis

### 🔎 Interactive Features

The dashboard includes interactive filters for:

- City
- Cuisine
- Rating
- Cost
- Restaurant Name

A Reset Filter option is also included to make dashboard exploration easier.
